# Data policy and latest user clarification

The source document provides all four RIP/OSPF link times. The later user clarification authorizes retaining every supplied value and calculating descriptive averages/comparisons across the four links. It supersedes the earlier request to prohibit all mixed means, while preserving the ban on falsely presenting assumptions as experimental verification.

R1–R2 is measured, single run. The other three links are Assumed (estimated – not measured), zero timed runs, no evidence IDs. Descriptive four-link averages include those estimates and always state that fact. No trial SD, error bars, confidence intervals or statistical significance is claimed. Per-link ratios/reductions inherit their input status. Reduction of averages is not an average of per-link percentages.

Missing numerical OCRT remains blank for no-loss OSPF B and unreliable RIP C. Those rows still retain recorded qualitative behaviour. OSPF C≈11s is an observed TTL/path-return interval, not outage OCRT. ExpB earlier/later runs are not directly comparable. Loss counts/percentages are absent because completed ping summaries are absent. E22 is preserved as unconfirmed and excluded as proof.

To replace an assumption with a real measurement, add the new timing, trial details and verified evidence; change status and run count; synchronize CSV/JSON/data.js; regenerate arithmetic/charts/report/deck; rerun validation. Do not promote estimates based only on illustrative topology logic.
